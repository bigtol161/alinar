# Дом Услуг

Сайт со статьями и заявками мастерам. Django, PostgreSQL.

## Модули
- config/ — настройки (settings.py) и главные адреса (urls.py).
- accounts/ — регистрация и роли (заказчик/исполнитель), модель Profile.
- news/ — вся логика: статьи, анкеты мастеров, заявки, личные кабинеты.
- orders/, core/ — пустые приложения от startapp, можно удалить после проверки.

## Как запустить
1. source venv/bin/activate
2. python manage.py runserver
3. Админка: /admin/

## Логика заявок
Заказчик отправляет заявку на странице мастера -> заявка видна
в его кабинете (my-leads) и у мастера (executor-leads) ->
мастер жмёт "Обработана", статус меняется у обоих.

## Аккаунты для проверки
