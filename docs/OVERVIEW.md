# Схема проекта alinar

Сайт статей с анкетами исполнителей: читатель смотрит публикации,
может подать заявку на мастера, а исполнитель получает заявки
в свой кабинет. Заявки живут по циклу: новая → обработана.

## Из чего состоит

- config/          — настройки Django (settings, корневой urls)
- accounts/        — профили пользователей: Profile с ролью
                     (заказчик или исполнитель) и её выбором при регистрации
- news/            — вся основная логика:
    статьи          — публикация, детальная страница со счётчиком просмотров
    анкеты          — карточки исполнителей с привязанным аккаунтом
    заявки (Lead)   — заказ на мастера: владелец, статус, закрытие
    кабинеты        — my-leads (у заказчика), executor-leads (у исполнителя)
- docs/            — документация: OVERVIEW.md и автокарта STRUCTURE.md

## Как устроены маршруты (приложение news)

    /                        → главная, список статей
    /stats/                  → статистика публикаций
    /executors/              → список анкет исполнителей
    /executors/<slug>/       → анкета мастера + форма заявки
    /<slug>/                 → детальная страница статьи
    /accounts/register/      → регистрация с выбором роли
    /accounts/logout/        → выход
    /my-leads/               → кабинет заказчика (требует входа)
    /executor-leads/         → кабинет исполнителя (требует входа)
    /leads/<pk>/done/        → закрыть заявку (кнопка у исполнителя)

## Жизнь заявки (основной сценарий)

    заказчик                исполнитель
       |                        |
    регистрация → роль "заказчик"
       |                        |
    открывает анкету          |
    заполняет форму  ───────→  Lead создаётся
    видит её в my-leads        | аккаунт анкеты видит заявку
       |                     в executor-leads
       |                     жмёт "обработана" → статус done
    видит смену статуса  ←──  |

## Что поддерживает актуальность документации

    docs/build_map.py  →  docs/STRUCTURE.md
    Запуск: python docs/build_map.py
    Скрипт сканирует приложения и urls, пишет классы, функции,
    docstring и маршруты. STRUCTURE.md вручную не править.
